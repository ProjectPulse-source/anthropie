{{- /* dossier.html — barre de dossier générique pour les blocs de /ressources/ (auteur, 03/10/2026 : « pour chaque dossier, le même type d'architecture que pour Dette »). Même organe que la barre dette (partials/dossier-barre.html). {{< dossier >}} en tête d'une page qui déclare `ressource.bloc` (notions, corpus, guides…) LA PRÉSENCE VIENT DU DÉPÔT : les onglets sont les pages de la langue courante qui déclarent le même `ressource.bloc`, triées par `ressource.rang` ; la pastille porte l'intitulé du bloc tel que l'index /ressources/ le déclare (`blocs` de content/ressources/_index*.md). Libellés : `onglet.long` (sinon le titre), `onglet.court` (téléphone ; sinon le libellé long), `onglet.role` (facultatif). Une page anglaise montre, dans un panneau « In French », les pages du bloc qui n'existent qu'en français. RÈGLE DE PRÉSENCE (auteur, 03/10/2026) : une barre à un seul onglet n'oriente pas le lecteur ; elle ne s'affiche qu'à partir de deux entrées (onglets et panneau compris). Un bloc d'une page n'a donc rien à afficher, en silence voulu, et reçoit sa barre automatiquement avec sa deuxième page. */ -}} {{- $page := .Page -}} {{- $en := eq $page.Lang "en" -}} {{- $bloc := .Get "bloc" | default $page.Params.ressource.bloc -}} {{- if not $bloc }}{{ errorf "dossier: aucun bloc (ni parametre bloc, ni ressource.bloc) dans %s" $page.File.Path }}{{ end -}} {{- $titre := "" -}} {{- with site.GetPage "/ressources" -}} {{- range .Params.blocs }}{{ if eq .id $bloc }}{{ $titre = .titre }}{{ end }}{{ end -}} {{- end -}} {{- if not $titre }}{{ errorf "dossier: bloc %q absent de l'index /ressources/ (%s)" $bloc $page.File.Path }}{{ end -}} {{- $pages := sort (where site.Pages "Params.ressource.bloc" $bloc) "Params.ressource.rang" -}} {{- $onglets := slice -}} {{- range $pages -}} {{- $o := .Params.onglet | default dict -}} {{- $long := $o.long | default .Title -}} {{- $onglets = $onglets | append (dict "url" .RelPermalink "titre" $long "court" ($o.court | default $long) "nom" (cond (hasPrefix $long ($o.court | default $long)) "" .Title) "role" $o.role "actif" (eq .RelPermalink $page.RelPermalink)) -}} {{- end -}} {{- $panneau := "" -}} {{- if $en -}} {{- $entrees := slice -}} {{- range site.Sites -}} {{- if eq .Language.Lang "fr" -}} {{- range sort (where .Pages "Params.ressource.bloc" $bloc) "Params.ressource.rang" -}} {{- if not .IsTranslated -}} {{- $o := .Params.onglet | default dict -}} {{- $entrees = $entrees | append (dict "url" .RelPermalink "titre" ($o.long_en | default ($o.long | default .Title)) "hreflang" "fr" "lang" (cond (isset $o "long_en") "en" "") "note" "in French") -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- with $entrees -}} {{- $panneau = dict "titre" "In French" "court" "French" "role" (printf "%d more" (len .)) "nom" "in French" "entete" "Pages of this section available in French only" "entrees" . -}} {{- end -}} {{- end -}} {{- $n := len $onglets -}} {{- with $panneau }}{{ $n = add $n (len .entrees) }}{{ end -}} {{- if ge $n 2 -}} {{- /* Aucune date : ces pages n'en déclarent pas toutes, et Hugo se replie sur la date de publication, qu'une mention « Mise à jour » donnerait pour une relecture (constat du 03/10/2026). */ -}} {{- partial "dossier-barre.html" (dict "page" $page "titre" $titre "label" $titre "items" $onglets "panneau" $panneau) -}} {{- end -}}
